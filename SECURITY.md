# Politique de sécurité

## Signaler une vulnérabilité

Merci de ne pas publier de détails exploitables dans une issue publique. Utilisez
les [avis de sécurité privés GitHub](https://github.com/4ymanee/Intelligent-recognition-of-plant-diseases/security/advisories/new)
pour transmettre une description, les étapes de reproduction et l'impact.

Si les avis privés ne sont pas disponibles, contactez le mainteneur du dépôt
via son profil GitHub.

## Bonnes pratiques de contribution

- Ne jamais committer de secrets, jetons, mots de passe ou fichiers `.env`.
- Ne pas inclure les environnements virtuels ni les jeux de données dans ce dépôt.
- Exécuter les contrôles de dépendances avant toute contribution.
- Utiliser des versions de dépendances corrigées et traiter les alertes de sécurité
  avant la fusion.
